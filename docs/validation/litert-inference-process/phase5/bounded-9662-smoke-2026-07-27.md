## Limits

This is one short, cold-session success per phone. It is enough to prove that
the pinned AAR can admit, compile, probe, and invoke the real 9662 model on
both available arm64 generations. It does not replace repeated full-song
runs, real GPU failure and CPU-fallback injection, disabled-GPU native
counters, foreground interaction traces, thermal qualification, or a
non-Samsung device matrix. Those checks remain open release-qualification
work and do not block implementation of the Phase 6 ownership contracts.

No MP3 fallback threshold, source-decode strategy, or window boundary changed
for this smoke.
